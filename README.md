# Wisent Tools

This repository no longer holds any code. Its Python package — the operator
runners, benchmark-evaluation scripts, activation helpers, the Stado object
client and its failure codes — was removed on 2026-09-24, together with
everything that existed only to build, version and publish that package.

Nothing here is built or released: `.wisent-release.json` declares
`releases: false` with that reason.

Versions of `wisent-tools` already published on PyPI (the newest recorded one
is 0.1.111) were not withdrawn. An environment that still installs one of them
keeps working as before, but nothing in this repository will produce a newer
one. The removed source stays reachable in Git history before this change.
